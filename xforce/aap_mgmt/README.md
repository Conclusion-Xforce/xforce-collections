# Ansible Collection - xforce.aap_mgmt

Collection of roles to manage and configure Ansible Automation Platform. It supports Ansible Automation Platform **>2.5**.

Work in progress.

## Contents

| Role                            | Description                                                                   |
| ------------------------------- | ----------------------------------------------------------------------------- |
| configure_controller            | Role to perform global Ansible Automation Controller configuration.           |
| manage_ctrl_exec_envs           | Role to manage the execution environments on Ansible Controller.              |
| manage_hub_collections          | Role to manage the collection repositories on Ansible Private AutomationHub.  |
| manage_hub_execenvs             | Role to manage the execution environments on Ansible Private AutomationHub.   |
